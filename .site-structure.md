# Kevin Schoenholzer Website - Site Structure Guide

**Internal documentation for editing/updating the website**
**Last updated: January 2025**

---

## Overview

- **Domain**: kevinschoenholzer.com
- **Hosting**: GitHub Pages (from this repository)
- **Framework**: Hugo static site generator with PaperMod theme
- **Repository**: kevisc.github.io

---

## How It Works

This site uses **pre-built HTML files** committed directly to the repository. GitHub Pages serves these static files. The Hugo build process happens locally, and the output HTML is committed to the repo.

## Key Files to Edit

### Homepage / Profile
- **File**: `config.yml`
- **What to edit**:
  - `profileMode.title` - Your name/title
  - `profileMode.subtitle` - Bio description
  - `socialIcons` - Links (CV, email, etc.)
  - `profileMode.buttons` - Navigation buttons (Research, Coding Projects)

### Adding/Editing Papers
Papers are in `papers/` directory. Each paper has its own folder with an `index.html`.

**To update an existing paper:**
1. Edit `papers/paperX/index.html`
2. Update these sections:
   - `<title>` tag
   - `<meta name=description>`
   - `<meta property="og:description">`
   - `<meta name=twitter:description>`
   - JSON-LD `"description"` and `"articleBody"`
   - `<h1 class="post-title">` (visible title)
   - `<div class=post-content>` (visible abstract)
3. Also update the summary in `papers/index.html`

**To add a new paper:**
1. Create new folder: `papers/paper4/`
2. Copy an existing `index.html` as template
3. Update all title, abstract, date, author, and URL references
4. Add entry to `papers/index.html` (papers listed newest first)

### Papers List Page
- **File**: `papers/index.html`
- Contains preview cards for all papers
- Each `<article class=post-entry>` is one paper card
- Order: newest papers at top

## Date Format

Dates appear in two formats in HTML files:
- ISO format: `2025-07-07T00:00:00+00:00` (in meta tags)
- Display format: `July 2025` (visible to users)

## Deployment

1. Make changes to HTML files locally
2. Commit changes: `git add . && git commit -m "message"`
3. Push to GitHub: `git push`
4. GitHub Pages automatically serves updated files
5. Changes live at kevinschoenholzer.com within minutes
