Educational Inequality Overview

This dashboard provides empirical analysis of educational inequalities using standardized assessment data. The analysis framework draws on social stratification theory (Bourdieu & Passeron, 1977; Coleman et al., 1966) to examine how socioeconomic factors correlate with student achievement outcomes.

Key Metrics Explained:
Inequality Index (Gini): Measures the dispersion of achievement scores (0 = perfect equality, 1 = maximum inequality).
SES Gradient (β): How much achievement increases per unit increase in socioeconomic status.
Mean Achievement: Average test score across all selected students and countries.

Score Distribution Analysis

Distribution analysis reveals patterns of educational achievement across selected countries using box plots, percentile analysis, and Lorenz curves.

Achievement Gap Decomposition

Decomposition of achievement gaps by socioeconomic status across and within countries (Reardon, 2011; Chmielewski, 2019).

Gap Measures:
Achievement Gap (Q4-Q1): Difference between top and bottom SES quartiles
Variance Decomposition: σ²_total = σ²_within + σ²_between
Effect Size (d): (Mean_high - Mean_low) / SD_pooled
Regression Analysis

OLS, Fixed Effects, and Random Effects regression models examining the relationship between socioeconomic status and achievement, with survey-weighted estimation following OECD (2023) guidelines.

Model Diagnostics

Model fit diagnostics including residual analysis and normality tests for all regression models.

Residual vs Fitted Values

Detects heteroscedasticity (non-constant variance). Points should be randomly scattered around the zero line.

Q-Q Plot (Normality Test)

Tests if residuals follow a normal distribution. Points should lie close to the diagonal reference line.

Comparative Analysis

Cross-country and cross-year comparison of inequality metrics, achievement gaps, and intergenerational effects.

Intergenerational Educational Stratification Map

Global view of how strongly parental socioeconomic status predicts student achievement. Darker red indicates stronger intergenerational effects (lower mobility).

Temporal Trends: SES Gradient Over Time

How the relationship between socioeconomic status and achievement changes over time for each country. Shows convergence or divergence patterns in educational mobility.

Variance Decomposition

Decomposition of total achievement variance into within-country and between-country components. Shows how much inequality exists within vs. across countries.
