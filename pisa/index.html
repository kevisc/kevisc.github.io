Educational Inequality Overview

This dashboard provides empirical analysis of educational inequalities using standardized assessment data. The analysis framework draws on social stratification theory (Bourdieu & Passeron, 1977; Coleman et al., 1966) to examine how socioeconomic factors correlate with student achievement outcomes.

Key Metrics Explained:
Inequality Index (Gini): Measures the dispersion of achievement scores (0 = perfect equality, 1 = maximum inequality).
SES Gradient (β): How much achievement increases per unit increase in socioeconomic status.
Mean Achievement: Average test score across all selected students and countries.

Score Distribution Analysis

Kernel density estimation and percentile analysis reveal patterns of educational achievement distribution across selected countries.

Achievement Gap Decomposition

Decomposition of achievement gaps by socioeconomic status across and within countries (Reardon, 2011; Chmielewski, 2019).

Gap Measures:
Achievement Gap (Q4-Q1): Difference between top and bottom SES quartiles
Variance Decomposition: σ²_total = σ²_within + σ²_between
Effect Size (d): (Mean_high - Mean_low) / SD_pooled
Regression Analysis

OLS regression analysis examining the relationship between socioeconomic status and achievement, with survey-weighted estimation following OECD (2023) guidelines.

Model Diagnostics

Overview

This application uses survey-weighted statistical methods following OECD (2023) technical standards for analyzing PISA data. All analyses account for the complex sampling design of international assessments.
