How to Cite

Academic Citation Guide for the PISA Educational Inequality Data Explorer

Note: If you use this tool in your research, we ask that you cite both the tool itself and the underlying PISA data source. This ensures proper attribution and helps track the tool's academic impact.

1. Citing This Tool

1.1 APA Format (7th Edition)

Schoenholzer, K. (2025). Educational Inequality Data Explorer [Web application]. https://kevinschoenholzer.com/pisa/

1.2 Chicago Style (17th Edition)

Schoenholzer, Kevin. 2025. "Educational Inequality Data Explorer." Web application. https://kevinschoenholzer.com/pisa/.

1.3 MLA Format (9th Edition)

Schoenholzer, Kevin. Educational Inequality Data Explorer. Web application, 2025, kevinschoenholzer.com/pisa/.

1.4 BibTeX

@misc{schoenholzer2025pisa, author = {Schoenholzer, Kevin}, title = {{Educational Inequality Data Explorer}}, year = {2025}, howpublished = {\url{https://kevinschoenholzer.com/pisa/}}, note = {Web application for analyzing educational inequality using PISA data} }

2. Citing the PISA Data

Important: Always cite the OECD PISA database as the data source, not just this tool. The tool is an interface to OECD data.

2.1 APA Format

OECD. (2023). PISA 2022 database. Organisation for Economic Co-operation and Development. https://www.oecd.org/pisa/data/

For specific assessment cycles:

OECD. (2019). PISA 2018 database. Organisation for Economic Co-operation and Development. https://www.oecd.org/pisa/data/2018database/

2.2 Chicago Style

OECD. 2023. "PISA 2022 Database." Organisation for Economic Co-operation and Development. https://www.oecd.org/pisa/data/.

2.3 BibTeX

@misc{oecd2023pisa, author = {{OECD}}, title = {{PISA 2022 Database}}, year = {2023}, publisher = {Organisation for Economic Co-operation and Development}, address = {Paris, France}, url = {https://www.oecd.org/pisa/data/}, note = {Accessed: [date]} }

3. Citing the learningtower R Package

If your analysis relies on data processed through the learningtower package, cite it as well:

3.1 APA Format

Vaughan, B., Stanke, L., Teng, T., Hyndman, R., & O'Hara-Wild, E. (2021). learningtower: OECD PISA datasets from 2000-2018 in an easy-to-use format (R package version 1.0.1) [Computer software]. https://CRAN.R-project.org/package=learningtower

3.2 BibTeX

@Manual{vaughan2021learningtower, title = {learningtower: OECD PISA Datasets from 2000-2018 in an Easy-to-Use Format}, author = {Belinda Vaughan and Lydia Stanke and Tiffany Teng and Rob Hyndman and Earo O'Hara-Wild}, year = {2021}, note = {R package version 1.0.1}, url = {https://CRAN.R-project.org/package=learningtower} }

4. Example Citations in Text

4.1 Methods Section

Data were analyzed using the Educational Inequality Data Explorer (Schoenholzer, 2025), a web-based application for analyzing PISA assessment data. The application uses data from the OECD PISA database (OECD, 2023), accessed via the learningtower R package (Vaughan et al., 2021). All analyses employ survey-weighted estimation following OECD (2023) technical standards.

4.2 Results Section

Using PISA 2018 data (OECD, 2019) analyzed through the Educational Inequality Data Explorer (Schoenholzer, 2025), we found that the socioeconomic gradient in mathematics achievement averaged 37.4 score points per standard deviation increase in ESCS (SE = 1.2, p < .001) across 35 OECD countries.

4.3 Data Availability Statement

Data Availability: The data used in this study are publicly available from the OECD PISA database (https://www.oecd.org/pisa/data/). Analysis code and documentation are available at the Educational Inequality Data Explorer (https://kevinschoenholzer.com/pisa/). Replication materials are available upon request.

6. Key References for Context

When discussing PISA methodology or educational inequality more broadly, consider citing these foundational works:

6.1 PISA Technical Documentation

OECD. (2019). PISA 2018 technical report. OECD Publishing. https://www.oecd.org/pisa/data/pisa2018technicalreport/
OECD. (2009). PISA data analysis manual: SPSS (2nd ed.). OECD Publishing. https://doi.org/10.1787/9789264056275-en

6.2 Educational Inequality Literature

Reardon, S. F. (2011). The widening academic achievement gap between the rich and the poor: New evidence and possible explanations. In R. Murnane & G. Duncan (Eds.), Whither opportunity? Rising inequality, schools, and children's life chances (pp. 91–116). Russell Sage Foundation.
Coleman, J. S., Campbell, E. Q., Hobson, C. J., McPartland, J., Mood, A. M., Weinfeld, F. D., & York, R. L. (1966). Equality of educational opportunity. U.S. Government Printing Office.
Bourdieu, P., & Passeron, J.-C. (1977). Reproduction in education, society and culture. Sage.

6.3 Survey Methodology

Rubin, D. B. (1987). Multiple imputation for nonresponse in surveys. John Wiley & Sons. https://doi.org/10.1002/9780470316696
