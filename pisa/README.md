## Key Features

### Data Loading
- **Progressive Loading**: Only fetches selected country-year combinations
- **Caching**: Loaded chunks stay in memory for session
- **Progress Tracking**: Real-time progress bar shows loading status
- **Error Handling**: Graceful degradation if some chunks fail

### Analysis Tabs

1. **Overview** - Summary statistics and key metrics (Gini, SES gradient, mean achievement)
2. **Distribution** - Score distributions, percentiles, Lorenz curves
3. **Achievement Gap** - SES-based gaps, variance decomposition
4. **Regression** - OLS models with survey weights
5. **Diagnostics** - Model fit, within/between variance
6. **Comparative** - Cross-country comparisons
7. **Methodology** - Statistical methods and citations

### State Management

The app uses a centralized state manager:

```javascript
import { getState, setState, subscribeToState } from './js/core/state-manager.js';

// Get current state
const state = getState();

// Update state
setState({ selectedCountries: ['USA', 'DEU'] });

// Listen to changes
subscribeToState((updates, newState) => {
    console.log('State changed:', updates);
});
```

### Data Loading API

```javascript
import { loadMetadata, loadSelectedData } from './js/core/data-loader.js';

// Load metadata on startup
const metadata = await loadMetadata();

// Load chunks for selected countries/years
const data = await loadSelectedData((progress) => {
    console.log(`Loading: ${progress.percentage}%`);
});
```

## Troubleshooting

### Data Loading Fails

1. Check that R scripts completed successfully
2. Verify files exist in `/pisa/data/country-year/`
3. Check browser console for specific errors
4. Ensure server is serving JSON files (correct MIME type)

### Metadata Not Found

1. Verify `metadata.json` exists in `/pisa/data/`
2. Check file path in `data-loader.js` matches your setup
3. Run `02-create-metadata.R` again

### Large File Size Warning

Total data size (~1 GB) may exceed GitHub's recommended limit. If issues arise:
- Use GitHub Releases for data files
- Or host data on AWS S3 / Cloudflare R2
- Update `DATA_BASE_URL` in `data-loader.js`
